# Purpose

The AI Engineer is responsible for designing, developing, integrating, and validating intelligent decision-making systems that enable autonomous UAV operation.

This role transforms perception outputs, mission objectives, and system state into intelligent behaviours through planning, reasoning, decision-making, task management, and autonomous mission execution.

The AI Engineer provides the cognitive layer of the UAV by determining **what actions should be taken** while delegating perception to the Computer Vision Engineer and motion execution to the Flight Control Engineer.

---

# Responsibilities

The AI Engineer shall:

- Design autonomous behaviour architecture.
- Develop mission planning systems.
- Develop behaviour planning.
- Develop decision-making algorithms.
- Develop task planning and scheduling.
- Integrate multi-sensor information.
- Develop autonomous target selection.
- Develop autonomous mission execution.
- Implement intelligent recovery strategies.
- Validate autonomous behaviour.

# Success Criteria

The AI Engineer has successfully completed the role when:

- Autonomous behaviour satisfies mission requirements.
- Decision-making is deterministic and traceable.
- Mission planning executes successfully.
- AI integrates correctly with perception and flight control.
- Safety constraints are always respected.
- Validation demonstrates robust autonomous operation.
- Documentation is complete and under configuration management.
