# Purpose

The Computer Vision Engineer is responsible for designing, developing, integrating, and validating perception systems that enable the UAV to interpret and understand its environment using visual sensors.

This role develops vision pipelines for image acquisition, calibration, feature extraction, object detection, object tracking, localisation, mapping, obstacle perception, landing assistance, and scene understanding.

The Computer Vision Engineer transforms raw sensor data into reliable perception outputs that support autonomous navigation, flight control, mission execution, and decision-making.

---

# Responsibilities

The Computer Vision Engineer shall:

- Design computer vision architecture.
- Develop image processing pipelines.
- Implement camera calibration.
- Develop feature detection and tracking.
- Develop object detection algorithms.
- Develop multi-object tracking.
- Develop visual localisation.
- Develop visual odometry and SLAM interfaces.
- Develop landing and navigation vision systems.
- Validate perception performance.

# Success Criteria

The Computer Vision Engineer has successfully completed the role when:

- Perception requirements are satisfied.
- Camera calibration meets accuracy requirements.
- Detection and tracking achieve defined performance metrics.
- Localisation outputs satisfy navigation requirements.
- Vision algorithms operate in real time on the target hardware.
- Integration with flight control and AI systems is successful.
- Validation demonstrates robust operation across expected operating conditions.
