# Purpose

The Test Engineer is responsible for planning, executing, documenting, and maintaining verification and validation (V&V) activities throughout the UAV engineering lifecycle.

The Test Engineer ensures that every system requirement is objectively verified through inspections, analysis, simulation, bench testing, ground testing, flight testing, or demonstration.

Testing provides objective engineering evidence that the UAV system satisfies its intended requirements and is safe for deployment.

---

# Responsibilities

The Test Engineer shall:

- Develop the Verification and Validation (V&V) Strategy.
- Develop Test Plans.
- Develop Test Procedures.
- Develop Test Cases.
- Develop Test Scripts.
- Manage the Requirements Verification Matrix (RVM).
- Conduct bench testing.
- Conduct integration testing.
- Conduct ground testing.
- Conduct flight testing.
- Perform regression testing.
- Analyse test results.
- Maintain objective test evidence.
- Support certification and safety reviews.

# Success Criteria

The Test Engineer has successfully completed the role when:

- Every requirement has a defined verification method.
- All planned tests have been executed.
- Objective evidence is collected and archived.
- Verification results are traceable.
- Validation demonstrates operational suitability.
- Test reports are approved.
- Test baseline is established.
