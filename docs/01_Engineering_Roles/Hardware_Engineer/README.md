# Purpose

The Hardware Engineer is responsible for designing, selecting, integrating, and validating the physical hardware that forms the UAV platform.

This role transforms the approved system architecture into a reliable hardware implementation by selecting components, designing electrical and mechanical integrations, ensuring compatibility between subsystems, and supporting manufacturing and testing.

The Hardware Engineer ensures that the hardware platform satisfies system requirements while meeting constraints such as weight, power consumption, reliability, maintainability, manufacturability, and cost.

---

# Responsibilities

The Hardware Engineer shall:

- Select hardware components.
- Design the electrical architecture.
- Design the power distribution system.
- Integrate sensors and payloads.
- Design mechanical mounting.
- Ensure electrical compatibility.
- Evaluate thermal performance.
- Manage hardware interfaces.
- Support manufacturing and assembly.
- Validate hardware performance.
