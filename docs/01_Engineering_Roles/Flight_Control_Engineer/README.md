# Purpose

The Flight Control Engineer is responsible for designing, implementing, integrating, and validating the flight control software that enables stable, safe, and autonomous operation of the UAV.

This role develops estimation, guidance, navigation, control, flight modes, actuator mixing, and failsafe logic while ensuring that the UAV satisfies mission performance and safety requirements.

The Flight Control Engineer transforms sensor data into reliable control commands that enable the aircraft to execute autonomous missions under varying operating conditions.

---

# Responsibilities

The Flight Control Engineer shall:

- Design flight control architecture.
- Develop state estimation algorithms.
- Implement sensor fusion.
- Develop guidance algorithms.
- Develop navigation algorithms.
- Design control algorithms.
- Implement actuator mixing.
- Develop flight modes.
- Implement failsafe behaviour.
- Validate flight performance.

# Success Criteria

The Flight Control Engineer has successfully completed the role when:

- Flight control requirements are satisfied.
- State estimation is accurate and robust.
- Guidance and navigation achieve mission objectives.
- Control loops are stable and meet performance targets.
- Flight modes operate as specified.
- Failsafe mechanisms function correctly.
- Flight testing validates safe and reliable operation.
