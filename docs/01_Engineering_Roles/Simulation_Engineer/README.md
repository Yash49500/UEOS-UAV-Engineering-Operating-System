# Purpose

The Simulation Engineer is responsible for designing, developing, maintaining, and validating simulation environments used throughout the UAV engineering lifecycle.

This includes physics simulation, Software-in-the-Loop (SITL), Hardware-in-the-Loop (HITL), sensor simulation, environmental modelling, scenario generation, digital twins, and simulation validation.

The Simulation Engineer enables rapid development, repeatable testing, safe experimentation, and early verification before physical integration.

---

# Responsibilities

The Simulation Engineer shall:

- Design simulation architecture.
- Develop simulation environments.
- Integrate UAV system models.
- Configure Software-in-the-Loop (SITL).
- Configure Hardware-in-the-Loop (HITL).
- Develop sensor simulation.
- Develop environmental models.
- Create mission scenarios.
- Validate simulation fidelity.
- Support verification and validation.
- Maintain simulation infrastructure.

# Success Criteria

The Simulation Engineer has successfully completed the role when:

- Simulation environments accurately represent the intended system.
- SITL and HITL environments are operational.
- Sensor models meet required fidelity.
- Mission scenarios are repeatable.
- Simulation results correlate with physical testing.
- Validation demonstrates acceptable simulation accuracy.
- Simulation assets are version controlled and documented.
