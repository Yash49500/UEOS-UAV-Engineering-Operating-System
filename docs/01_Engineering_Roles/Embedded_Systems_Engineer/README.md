# Purpose

The Embedded Systems Engineer is responsible for designing, developing, integrating, and validating the embedded software that interfaces directly with the UAV hardware platform.

This role transforms the validated hardware platform into an operational system by implementing firmware, hardware abstraction layers, peripheral drivers, communication interfaces, boot processes, and real-time software.

The Embedded Systems Engineer ensures that embedded software is reliable, deterministic, maintainable, efficient, and fully compatible with the hardware architecture.

---

# Responsibilities

The Embedded Systems Engineer shall:

- Develop embedded firmware.
- Implement hardware abstraction layers (HAL).
- Develop peripheral drivers.
- Configure microcontrollers and processors.
- Develop boot and startup software.
- Integrate RTOS where applicable.
- Implement communication interfaces.
- Support hardware bring-up.
- Optimise embedded performance.
- Validate embedded software.
