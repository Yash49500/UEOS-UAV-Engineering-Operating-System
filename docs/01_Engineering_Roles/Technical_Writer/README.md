# Purpose

The Technical Writer is responsible for creating, reviewing, organising, maintaining, and publishing all engineering documentation throughout the UAV engineering lifecycle.

The role ensures that engineering knowledge is communicated accurately, consistently, and in a structured manner for developers, reviewers, operators, maintainers, and future engineering teams.

Documentation is treated as an engineering deliverable and configuration-controlled artefact—not an afterthought.

---

# Responsibilities

The Technical Writer shall:

- Develop documentation standards.
- Maintain document templates.
- Produce system documentation.
- Produce subsystem documentation.
- Produce API documentation.
- Produce integration guides.
- Produce installation guides.
- Produce operation manuals.
- Produce maintenance manuals.
- Produce troubleshooting guides.
- Produce release notes.
- Maintain documentation traceability.
- Review engineering documents.
- Manage documentation versioning.
- Publish documentation.

# Success Criteria

The Technical Writer has successfully completed the role when:

- All required engineering documentation exists.
- Documentation is technically accurate.
- Documentation is version controlled.
- Documentation is traceable to engineering artefacts.
- Documentation follows UEOS standards.
- Documentation is reviewed and approved.
- Documentation is published and maintained.
